# Final Audit

## Repair summary

- Mobile GraphQL now requires an explicitly configured external HTTP(S) endpoint through `EXPO_PUBLIC_GRAPHQL_ENDPOINT`; it no longer silently targets a local web-app route that does not exist.
- Added endpoint validation and regression tests for missing/invalid configuration and confirmed an unconfigured endpoint does not trigger a network request. Cached data remains available when refresh fails, and the configuration error is surfaced.
- Improved real-time subscription lifecycle and reconnect handling, with regression coverage for callback removal, topic/source routing, failed sends, and resubscription.
- Updated mobile and workspace setup documentation and formatted modified files so repository lint passes.

## Remaining issues and limitations

- E2E results are nondeterministic in the full suite. External news/API availability and rate limiting were observed during the run; the isolated tests passed, but a clean full-suite rerun is still needed to establish stability.
- The mobile app needs a reachable external GraphQL HTTP(S) endpoint. The static web app does not expose `/graphql`; no live external endpoint was supplied, so end-to-end mobile/backend connectivity could not be verified here.
- `EXPO_PUBLIC_GRAPHQL_ENDPOINT` is bundled into the client. Do not put credentials or private API keys in Expo public variables; authentication and secrets must be handled by the external service using an appropriate secure design.
- The build/check output notes that the checked-in Browserslist data is old and that SvelteKit overrides the configured Vite `build.outDir`; neither prevented the checks from passing.

## Repository safety

- The workspace and nested application already had substantial local modifications. Changes were kept scoped to the repair and documentation; pre-existing work was not reverted.
- `.env.example` is a template. Real environment files and credentials must remain untracked and must not be committed.
- No destructive Git operations, commits, pushes, or deployments were performed.
